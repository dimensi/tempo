# nutrition

Дневник отображает нормализованные записи и их вычисленные итоги. UI не пересчитывает питание и не заменяет неизвестные значения известной частью суммы. Сравнение со сводкой YAZIO раскрывается отдельно; расхождения и неполные итоги остаются видимыми.

Поверхность ограничена 960 px. КБЖУ имеют одинаковые цвета и текстовые подписи на уровне дня, приёма пищи и записи. На телефоне значения располагаются в две колонки, записи — отдельными строками внутри приёма пищи. Отсутствующие необязательные сведения о порции/массе скрыты, реальные нули сохранены. Компактная полоса «Соотношение БЖУ по массе» доступна только при трёх известных неотрицательных значениях и положительной сумме; это не прогресс до цели. Контракт не содержит цели, поэтому колец прогресса нет.

Фото сопоставляются точно по `date` и `daytime` безопасного DTO и показываются с `contain`. DTO связывает фото с приёмом пищи за день, а не с отдельной продуктовой записью: название блюда не используется для сопоставления. Ручное удаление по-прежнему требует подтверждения; фото YAZIO доступны только для просмотра. Загрузка в дневнике отсутствует.

`tests/e2e/diary-ui.spec.ts` использует только синтетические данные и проверяет desktop/mobile, частичные и нулевые итоги, сравнение, условную полосу БЖУ, группировку фото и подтверждение удаления. Изображения тестов не являются пользовательскими фотографиями.
