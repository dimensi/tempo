# Reports

The authorized owner/trainer report opens its HTML preview automatically after hydration and updates it after a 300 ms settled date/period selection. Reports and Diary share the same calendar day strip, date jump and Today action. Today uses the browser’s IANA timezone; daily and inclusive seven-day ranges preserve the selected date and custom end edits. Controls use at least 16 px text without restricting browser zoom.

The previous successful preview remains visible, labelled with its own range, while the next report loads. Aborted/stale requests cannot overwrite it. Explicit 401/403 responses from preview or Download purge retained private HTML, its range and its successful request key; the denied selection waits for another user edit before attempting preview again. Recoverable rendering errors preserve the prior preview and all date/period choices. Unmount and selection changes abort preview requests; the server checks cancellation between HTML source reads and closes Chromium if a PDF export is cancelled. PDF rendering happens only after Download. Downloads and previews use the existing owner-scoped, private/no-store endpoint without a persistent report cache.

HTML preview uses the same escaped content, values, colors and photos in natural flow, without launching Chromium or measuring A4 pages. Download alone uses exact PDF pagination; preview page boundaries may differ. Rendering, source adaptation, photo selection, embedded font licensing, authorization, limits and verification are documented in [the PDF runtime guide](../../server/pdf/README.md). No feature imports another feature, and the browser receives no server credentials or database access.
